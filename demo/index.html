Interactive OKLCH Color Picker

Explore the modern OKLCH and OKLAB color spaces with an interactive color picker.

This is a free interactive color picker for the modern OKLCH and OKLAB color spaces. Experiment with perceptually uniform colors directly in your browser, compare colors, explore hue and chroma, and create better color palettes for design, visualization, and user interfaces.

Why OKLCH?

Unlike RGB, HSL, or HSV, the OKLCH color space was designed to be perceptually uniform. Equal changes in lightness, chroma, or hue produce much more predictable visual results, making it an excellent choice for modern user interfaces, data visualization, branding, and accessible color design.

Features

  • Interactive OKLCH color picker
  • Explore the OKLAB color space
  • Create perceptually uniform color palettes
  • Visualize lightness, chroma, and hue
  • Modern CSS color support
  • Runs entirely in your browser

Who is this tool for?

This tool is intended for designers, developers, researchers, and anyone interested in modern color science. Whether you're creating accessible interfaces, simply learning about perceptual color spaces, this application provides an interactive environment for exploration. For most users, the first tab containing the color picker is all you'll need. The remaining tabs showcase additional features and demonstrate how the egui extension can be embedded into Rust applications.

About this project

This interactive color picker is a demonstration of the egui_oklch_color_picker Rust library. The repository contains the reusable widgets and utilities needed to integrate modern OKLCH and Oklab color pickers into applications built with egui. This website serves as a live showcase of the library's capabilities and allows you to experiment with the widgets directly in your browser.

Credits

The user interface is built with egui and eframe, enabling the application to run natively and on the web through WebAssembly.

The design of the primary color picker was inspired by A Better Way To Color Pick and the oklab_colour_picker_krita project for Krita.

If you're interested in learning more about the OKLCH color space, a great starting point is oklch.fyi, which provides an accessible introduction to perceptually uniform color spaces and modern CSS color workflows.
